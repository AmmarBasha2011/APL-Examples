# APL-Examples — أمثلة لغة APL

أمثلة جاهزة للغة APL، كل مثال له رقم واسم وملف. العدد الحالي: 120 مثال.

## تحميل مثال

```
عمار مثال حمل <الرقم أو الاسم>
```

بينزّل المثال في المجلد اللي انت واقف فيه.

## تجربة مثال

```
عمار مثال جرب <الرقم أو الاسم>
```

بينزّل المثال ويشغّله على طول عشان تشوف نتيجته قبل ما تستخدمه.
