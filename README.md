# APL-Examples — أمثلة لغة APL

أمثلة جاهزة للغة APL، كل مثال له رقم واسم وملف. العدد الحالي: 4105 مثال.

كل مثال بيشتغل من غير تثبيت أي مكتبة ومن غير ما يستنى إدخال، ومتفحص بمدقق الأمثلة بتاع APL (`tools/verify_examples.py`) في المفسّر وفي الـ playground.

## تحميل مثال

```
عمار مثال حمل <الرقم أو الاسم>
```

بينزّل المثال في المجلد اللي انت واقف فيه.

## تجربة مثال

```
عمار مثال جرب <الرقم أو الاسم>
```

بينزّل المثال ويشغّله على طول عشان تشوف نتيجته قبل ما تستخدمه.

## قايمة الأمثلة

الجدول الكامل (4105 سطر) كبير على صفحة README، فالقايمة الكاملة في `index.json` (الرقم والاسم والملف والملخص)، وكل الملفات في مجلد `examples/`. الأمثلة مرقمة والرقم ثابت.

## الفهرس للأدوات

ملف `index.json` فيه الرقم والاسم والملف والملخص لكل مثال بصيغة JSON، ومدير الأمثلة في APL بيقراه.

## الرخصة

PSF-2.0، زي APL وبايثون.
